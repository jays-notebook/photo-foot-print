# Application icon

`app-icon.png` is the RGBA master for Photo Foot Print's desktop icon. The photo
frame and location pin represent adding a location to a scanner photograph.
The original was generated with the built-in image generation tool; transparent
corners are intentional. Platform icons are derived with the Tauri CLI.

To regenerate the desktop assets, run:

```sh
npm run tauri -- icon assets/app-icon.png --output /tmp/pfp-icons
```

Copy the generated `32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.ico`
and `icon.icns` into `crates/src-tauri/icons/`, and copy the master there as
`icon.png`. Mobile assets generated by the CLI are not used by this application.
Inspect small sizes and retain the alpha channel. Native CI compares the
packaged Windows icon resources and macOS ICNS with these source assets.

## Generation prompt

Use case: logo-brand. Create a polished original desktop application icon for Photo Foot Print, a private film/slide-scanner JPEG photo geotagging app that adds a map location to a photograph. Asset: a single square 1024 x 1024 RGBA application-icon master, not a mockup or presentation. Design: a bold warm ivory instant-photo frame containing a very simple green-blue landscape, with a large coral-orange location pin integrated into the lower-right portion of the photo. Put this coherent photo-and-location symbol on a deep teal rounded-square tile. Use clean, beautifully balanced geometric shapes and restrained dimensional shading, crisp silhouettes, a few strong colors, and generous proportions so the photograph and map pin remain clear at 16, 32, and 128 pixels. The pin is a simple iconic solid shape with one circular cutout; no tiny map details. Center the tile and symbol; the tile fills about 88 percent of the canvas with equal breathing room. Outside the rounded tile must be genuinely transparent, with smooth antialiased edges and no opaque black or white rectangle. The tile itself stays opaque and rich teal, with an ivory photo border and vivid coral accent for legibility in both light and dark OS docks. Front-facing, no tilt or perspective. No text, letters, numbers, typography, watermarks, extra objects, UI, device, grid, or background scene. This is final usable icon artwork.
